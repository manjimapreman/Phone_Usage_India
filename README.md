
 # India Phone Usage Analysis Dashboard
  ## Project Overview
This project presents an interactive India Phone Usage Analysis Dashboard developed using Microsoft Excel. The dashboard analyzes smartphone usage patterns, screen time, mobile data consumption, phone brands, operating systems, and digital activities.

The main objective is to understand how people use smartphones across different age groups and categories.

## Key Performance Indicators (KPIs)
- Total Users: 17,686
- Average Screen Time: 6.55 hours/day
- Average Data Usage: 25.41 GB/month
- Average Apps Installed: 104.58 apps/user
- Average Monthly Recharge: 1,042.79

## Dashboard Features

### Interactive Filters
- Gender
- Age Group
- Phone Brand
- Operating System
- Primary Use

### Data Visualizations
1. Average Daily Screen Time by Age Group
2. Number of Users by Phone Brand
3. Operating System Distribution
4. Average Daily Time Spent on Digital Activities
5. Average Monthly Data Usage by Age Group
6. Number of Users by Primary Use

## Tools and Technologies
- Microsoft Excel
- Pivot Tables
- Pivot Charts

- Data Cleaning
- Data Visualization

## Key Observations
- The average daily smartphone screen time is 6.55 hours.
- Average monthly mobile data usage is 25.41 GB.
- Android and iOS have nearly equal representation in the dataset.
- Education is the highest primary-use category in the dashboard.
- Streaming has the highest average daily usage among the three digital activities displayed.
